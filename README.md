## Inspiration
In the realm of software development, business, research, etc..., it can be difficult to begin or continue a project with the limitations of your own skill set.

## What it does
Atlanticus is a web app built for the purpose of connecting students at Cal Poly across different majors and interests. Users can explore others' projects, create their own projects, and match themselves with others's projects and Cal Poly faculty. Using the AI integration, a user can use any keywords in their profile to match themselves with projects. Additionally, users can use any keywords to search for Cal Poly faculty they may want to connect with.

## How we built it
Next.js was used for the frontend development. Supabase was used as the database to store the projects, join requests, profiles, and project owners. For the AI integration, we used the OpenAI API. The app was deployed with Vercel on the domain _ atlanticus.jakeo.dev _.

## Challenges we ran into
We ran into a few problems involving the AI/Supabase Vercel integration and the deployment. Notably, deployments only happen automatically upon Github when the owner merges them. Additionally, we had to figure out the integration of AI and Supabase with Vercel. Also, we were learning how to use AI agents to generate code.

## Accomplishments that we're proud of
We were able to fully deploy the website within the time limit. We also learned a lot about using Next.js, Typescript, Supabase, Vercel, Tailwind, etc...
